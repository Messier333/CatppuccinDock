# 포털 사용 안내

[프로젝트 소개·실행](../README.md)

## 권한과 북마크

- **관리자**: 본인 북마크, 계정·2FA, 사용자 생성·활성화·권한·비밀번호, 공통 포털·OIDC 설정, SSO 계정 연결, 리버스 프록시 API 링크 가져오기.
- **일반 사용자**: 본인 북마크, 계정·비밀번호·2FA 관리. 관리자 API에는 접근할 수 없습니다.
- 사용자별 탭·카테고리·북마크를 PostgreSQL에 저장합니다. 이름·주소·아이콘·색상·순서·배너를 수정할 수 있고, 다른 사용자 소유의 항목은 조회·수정할 수 없습니다.
- 마지막 활성 관리자는 일반 사용자로 변경하거나 비활성화할 수 없습니다. 권한·계정 상태·비밀번호 변경 시 해당 사용자의 기존 세션을 폐기합니다.

`backend/app/data/startpage.json`은 새 사용자에게 복사할 기본 북마크입니다. 계정이 만들어진 뒤에는 DB가 원본이며, 재시작해도 편집한 데이터가 초기화되지 않습니다.

기존 단일 관리자 버전에서 업그레이드하면 기존 계정·비밀번호·유효한 세션을 관리자 계정으로 이전하고 기본 북마크를 한 번만 저장합니다. 이전은 트랜잭션으로 실행하며 기존 테이블을 삭제하지 않습니다. `postgres_data` 볼륨은 유지하세요.

## GIF 검색·서버 저장·메뉴 배경

**설정 → 내 북마크 → 탭 추가 또는 탭 수정 → GIF 검색·선택**에서 제공처와 검색어를 선택합니다. 기본은 **통합 검색**이며 **GIFDB·Alpha Coders·MotionBgs**를 함께 검색합니다. GIFDB는 자유 검색을 지원하고, MotionBgs는 도시·자연 풍경의 주제별 목록을 제공합니다. **관리자 → GIF · 배경 관리**에 Pixabay API 키를 등록하면 공식 영상 검색도 포함되며, 선택한 영상은 처음 최대 20초를 GIF로 변환해 저장합니다. 픽셀 아트·도시 야경·자연 풍경·숲·바다·비·애니 풍경·노을 주제 버튼을 제공합니다. MotionBgs는 주제별 목록을 검색하며, 한글 검색어도 주요 풍경 키워드에 맞춰 찾습니다. Wikimedia Commons·Openverse도 일반 GIF 제공처로 남아 있습니다. 검색 결과를 누르면 GIF를 서버로 다운로드하며, 마지막으로 탭의 **저장**을 눌러 적용합니다. 직접 **GIF 업로드**도 가능합니다. 기존 바다·풍경·휴식 프리셋은 제거했으며, 기본은 **배경 없음**입니다. 저장한 GIF를 다른 탭에 다시 지정하거나 배경 없음으로 바꿀 수 있습니다.

검색 결과의 미리보기만 외부 사이트에서 불러옵니다. 적용한 GIF는 외부 사이트의 가용성과 관계없이 서버에서 표시하며, 애니메이션·출처·작성자·라이선스를 함께 보관합니다. 저장 한도에 맞는 GIF는 원본 바이트를 유지하고, 큰 GIF는 최적화한 파일을 보관합니다. GIF 파일은 비공개 Garage/S3 버킷에 저장하고, PostgreSQL에는 소유권·출처·저장 경로를 보관합니다. Garage의 `garage_meta`·`garage_data` Docker 볼륨에 보존되며 기존 DB 파일의 이관은 [스토리지 운영 안내](storage.md)를 참고하세요. 일반 사용자도 본인 배경을 관리할 수 있고 다른 사용자의 업로드는 조회하거나 지정할 수 없습니다. 재시작·프런트엔드 재배포 후에도 유지되며 앱의 JSON·암호화 백업에 파일 본문이 포함됩니다. 서버 전체 백업에는 DB와 Garage 스토리지가 함께 필요합니다. 선택을 취소한 파일도 내 목록에 남아 다음에 선택하거나 삭제할 수 있습니다.

GIFDB·Alpha Coders·MotionBgs 검색은 API 키 없이 동작합니다. Pixabay는 관리자 화면에 API 키를 등록해야 하며, 키는 암호화하여 저장하고 사용자에게 전달하지 않습니다. 공식 Pixabay 응답은 재시작 후에도 24시간 캐시합니다. GIPHY는 웹 검색 바로가기를 제공하며 API 자산을 자동 복사하지 않습니다. GIFDB·Alpha Coders·MotionBgs는 공개 검색·다운로드 페이지를 이용하므로 제공처의 페이지 구조 변경이나 검색 제한·장애가 있으면 다른 제공처나 직접 업로드를 사용할 수 있습니다. 파일별 이용조건과 작성자는 원본 출처에서 확인할 수 있습니다. 파일과 출처 정보는 JSON·암호화 백업에도 포함됩니다. [Alpha Coders 픽셀 GIF](https://alphacoders.com/pixel-art-gifs) · [MotionBgs 자연 GIF](https://motionbgs.com/gifs:nature/) · [Openverse API 문서](https://api.openverse.org/v1/) · [Wikimedia API 문서](https://commons.wikimedia.org/wiki/Commons:API/MediaWiki)

검색 다운로드와 직접 업로드 모두 원본 최대 100MB, 사용자당 최대 20개입니다. 10MB·4096픽셀·500프레임·전체 프레임 2억 픽셀의 저장 범위를 넘는 GIF는 해상도·프레임·색상 수를 자동으로 줄여 10MB 이하의 GIF로 저장합니다. 최적화 시 비율·총 재생 시간·반복 설정·투명도를 유지하며, 큰 배경은 최대 960×540 안에 맞춥니다. 원본의 처리 범위는 각 변 8192픽셀·한 프레임 1677만 픽셀·2400프레임·전체 40억 픽셀까지이며, 작업은 한 번에 하나씩 별도 프로세스에서 메모리 512MiB·최대 60초로 제한합니다. 처리할 수 없는 파일은 저장하지 않습니다. 검색 결과가 없는 주제의 404 응답은 빈 목록으로 표시합니다. 같은 파일을 다시 올려도 저장 개수는 늘어나지 않습니다. 업로드 목록의 GIF를 선택하면 사용 중인 탭 수를 볼 수 있으며, 사용하지 않는 파일은 삭제할 수 있습니다. 탭에서 사용하는 파일은 먼저 탭의 배경을 변경하고 저장한 뒤 삭제하세요.

**GIF · 배경 관리**에서 일반 사용자의 가져오기/업로드 허용 여부와 분당·일일 횟수, 일일 원본 용량, 사용자·서버 저장 용량을 설정합니다. 기본은 일반 사용자 분당 1회·하루 5회·원본 200MiB, 개인 저장 200MiB·20개, 전체 하루 100회·원본 2GiB·저장 2GiB입니다. 다운로드/업로드 전에 DB 트랜잭션으로 사용량과 저장 공간을 검사하고, 진행 중 용량을 예약하며 서버 전체에서 한 작업만 허용합니다. 실패도 횟수와 실제 받은 바이트를 소비하며 삭제·재로그인·서버 재시작으로 초기화되지 않습니다. 비정상 종료로 남은 예약은 보수적으로 사용량에 남고 작업 잠금은 5분 뒤 만료됩니다. 일일 기준은 공통 시계 시간대의 자정입니다. 백업 복원에도 개인·전체 저장 용량 제한을 적용합니다. 같은 계정의 검증된 제공처 항목은 네트워크 없이 재사용하고, 다른 계정의 서버 검증 캐시는 개인 파일로 복사합니다. 백업에 사용자가 적은 출처 정보는 공유 캐시의 근거로 사용하지 않습니다.

이미지 응답은 로그인·소유권 확인 후 전송합니다. 브라우저가 이미 받은 파일은 ETag로 확인하여 변경이 없으면 본문 전송을 생략합니다. 배경 파일은 탭·북마크 JSON 목록에 포함하지 않습니다.

## 시간 표시

**설정 → 포털 설정 → 시간 표시 형식**에서 **24시간(18:30)** 또는 **12시간 AM/PM(06:30 PM)**을 선택합니다. 시간대는 한국이면 `Asia/Seoul`을 사용하세요. 메인 날짜와 시계에 같은 시간대를 적용하며 컴퓨터의 현재 시각을 초 단위로 갱신합니다. 24시간 형식의 자정은 `00:00`입니다. 초기 설정의 `UA`(키이우) 보조 시계는 제거하여 하나의 시계만 표시합니다. 이전 버전의 형식은 최초 갱신 시 기본 24시간으로 정리하고 기존 시간대는 유지합니다.

## 메인 패널 온도

설정에 저장된 도시명을 Open-Meteo 지오코딩 API로 좌표로 변환한 뒤 현재 기온을 조회합니다. 도시명을 입력하고 동명이면 `Seoul, KR`처럼 국가를 함께 입력하세요. API 키는 필요하지 않습니다. 섭씨·화씨를 지원하고 서버에서 10분 동안 결과를 재사용합니다. 공급자 장애는 1분 후 다시 조회하며 메인 위젯을 눌러 재시도할 수 있습니다. 실패하면 `조회 불가`와 원인 안내를 표시합니다.

기온: [Open-Meteo](https://open-meteo.com/en/docs), 위치 정보: [GeoNames / Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api). 서버에서 해당 두 API로 HTTPS 접속이 가능해야 합니다.

## 관리자 공개 링크와 개인 메인 패널

API 링크 미리 보기에서 **가져온 링크 사용 방식 → 선택한 링크를 일반 사용자에게 공개**를 선택하고 공개할 항목만 체크합니다. **공개 링크 관리**에서 이름·아이콘·색상을 수정하거나 공개를 해제할 수 있습니다. API에서 조회했다는 이유만으로 전체 도메인이 공개되지는 않습니다. 서비스 연결을 삭제해도 이미 공개한 링크는 보존되므로 공개 링크 관리에서 별도로 공개 해제하세요.

일반 사용자는 **설정 → 공개 링크**에서 검색어 없이 허용된 전체 목록과 공개 개수를 확인할 수 있습니다. 체크박스로 여러 링크를 선택하거나 목록 전체를 선택한 뒤 **카테고리 → 세부 카테고리** 순서로 저장할 위치를 선택한 다음 **선택한 N개 메인에 추가**를 누릅니다. 개별 링크의 **메인에 추가**도 사용할 수 있습니다. 세부 목록에는 선택한 카테고리의 항목만 표시되며, 카테고리를 바꾸면 세부 선택은 초기화됩니다. 두 단계를 모두 선택해야 추가할 수 있습니다. 다른 사용자의 카테고리에 저장할 수 없으며 같은 URL은 중복 추가하지 않습니다. 이 목록에서 추가한 링크는 관리자가 공개를 해제하면 다음 조회부터 메인 패널과 개별 링크 API에서 숨겨집니다. 다시 공개하면 기존 배치가 복원됩니다. 사용자가 독립적으로 만든 개인 북마크는 영향을 받지 않습니다. 공개 링크의 이름·아이콘·위치는 개인화할 수 있고 주소는 관리자가 관리합니다. 이는 포털에서 링크를 표시하는 권한이며 대상 서비스의 접근 권한을 부여하거나 철회하지는 않습니다.

## 아이콘 검색·선택·업로드

북마크 추가·수정과 공개 링크 설정에서 이름을 입력한 뒤 **아이콘 검색·선택**을 누르면 해당 이름으로 먼저 검색합니다. 검색어와 컬렉션은 직접 바꿀 수 있으며, 다른 북마크를 편집할 때 이전 검색 상태가 남지 않습니다. 기존 아이콘 외에 Iconify의 Tabler, Simple Icons, Material Design Icons 세트를 검색·미리 보기·페이지 단위로 탐색할 수 있습니다. 앱 로고는 Simple Icons에서, 일반 기호는 Tabler·Material Design에서 찾을 수 있습니다. `server`, `docker` 같은 영문 검색 및 `서버`, `도커`, `검색` 등 자주 쓰는 한국어 키워드를 지원합니다.

아이콘 색상은 기본 **자동**입니다. 각 카테고리에서 화면에 보이는 순서대로 **초록 → 복숭아 → 빨강 → 파랑 → 보라**를 반복하며 순서 변경·카테고리 이동과 라이트·다크 테마를 반영합니다. 검색 결과에서도 원래 카테고리의 색상을 유지합니다. **아이콘 색상 직접 지정**을 켜면 선택한 색상을 고정하고, 끄면 자동 모드로 돌아갑니다. 공개 링크의 기본 색상도 자동이며 사용자가 메인에 추가한 위치에 맞춰 결정됩니다. 기존 기본 북마크 중 이름·주소·아이콘·색상이 초기 설정과 같은 항목은 자동으로 전환하고, 사용자가 수정한 색상은 보존합니다.

외부 목록은 서버에 포함하여 실행 중 외부 아이콘 API 장애나 요청 지연에 영향을 받지 않습니다. 브라우저에 전체 아이콘 데이터를 내려보내지 않고 48개씩 검색 결과를 반환하며 실제 SVG는 같은 서버에서 제공합니다. 아이콘 출처·버전 지문·원래 라이선스는 `backend/app/data/iconsets/`에 보존합니다. 검색 아이콘 식별자는 `simple-icons:docker` 형태이며 외부 아이콘 URL은 직접 입력하지 않습니다.

**내 아이콘·업로드 → 아이콘 파일 업로드**에서 PNG·JPG·WebP·SVG·ICO·GIF를 올릴 수 있습니다. 원본은 최대 5MiB이며 비율·투명도를 유지해 128×128 PNG로 저장합니다. GIF는 첫 프레임을 사용합니다. 업로드 이미지는 원래 색상을 표시하므로 아이콘 색상 선택 대신 이미지 자체의 색상을 사용합니다. SVG는 이미지로 변환하며 외부 파일·주소를 불러오지 않습니다.

**내 아이콘·업로드**를 누르면 본인이 올린 파일을 미리보기 목록으로 보고 선택할 수 있습니다. 파일 이름으로 검색하고 여러 북마크에 재사용할 수 있습니다. 업로드·선택 후에도 목록이 유지되며 선택한 아이콘에 테두리가 표시됩니다. 같은 이미지의 재등록은 기존 파일을 재사용합니다. 북마크 편집·메인 빠른 추가·다중 편집·관리자의 공개 링크 설정에서 사용할 수 있고, 사용하지 않는 파일은 삭제할 수 있습니다. 북마크·공개 링크·휴지통에서 참조하는 파일은 삭제할 수 없습니다. 파일 수는 계정별 100개, 서버 전체 아이콘 저장 용량은 128MiB이며 업로드 시도는 계정·접속 IP별 15분에 10회로 제한합니다.

파일은 비공개 Garage의 `icons/` 경로에 저장하며 DB에는 소유권·이름·용량·저장 경로를 보관합니다. 타인의 비공개 아이콘은 조회하거나 지정할 수 없습니다. 관리자가 공개 링크에 지정한 아이콘은 해당 링크를 볼 수 있는 사용자에게만 제공하며, 공개 권한을 회수하면 파일 조회도 거부합니다. JSON·암호화 백업의 **업로드한 GIF·아이콘 포함**을 켜면 아이콘 파일도 포함되고 다른 계정·서버에 복원할 때 파일 ID와 북마크 연결을 새로 매핑합니다. 이미지 포함을 끄면 백업의 업로드 아이콘 참조는 기본 아이콘으로 바꿔 독립적으로 복원할 수 있도록 합니다.

## 드래그 정렬·통합 검색

**내 북마크**에서 탭·카테고리·링크 왼쪽 손잡이를 드래그하면 순서가 자동 저장됩니다. 마우스와 터치를 지원하고, 손잡이에 키보드 초점을 둔 후 방향키로도 이동할 수 있습니다. 정렬은 본인 목록에만 적용하며 한 번에 저장합니다. 저장 실패 시 원래 순서로 복원하고 최신 목록을 다시 읽습니다. 기존 표시 순서 숫자 입력도 사용할 수 있습니다.

메인·관리자·로그인 화면은 전역 색상표와 공통 컨트롤 스타일을 사용합니다. 페이지 및 패널·검색 결과·아이콘 목록·드롭다운의 스크롤바, 입력창, 체크박스, 자동 입력, 포커스 표시, 팝업 배경은 다크·라이트 테마에 함께 맞춰집니다. 등록 화면의 드롭다운은 공통 테마 UI를 사용합니다. 펼친 옵션, 선택 표시, 키보드 방향키·Enter·Escape, 긴 목록 스크롤, 화면 아래에서 위로 펼치기와 모바일 폭 조정을 지원합니다.

메인에서 `←`·`→`로 이전·다음 탭을 선택하며 처음과 마지막 탭은 서로 이어집니다. 방향키·좌우 버튼·탭 선택 시 이동 방향에 맞춰 배경과 링크 패널이 함께 슬라이드합니다. 시스템의 모션 감소 설정을 사용하면 애니메이션 없이 전환합니다. 검색 중이거나 입력창에 초점이 있을 때는 탭이 바뀌지 않습니다. `1`~`9`로 해당 순서의 탭을 바로 선택할 수도 있습니다.

메인 검색 버튼 또는 `S`로 통합 검색을 엽니다. 모든 탭의 본인 북마크 이름·주소와 탭·카테고리를 검색하고, 각 결과에 위치를 표시합니다. 북마크를 선택하면 새 탭에서 열고, 아무 결과도 선택하지 않은 상태에서 Enter를 누르면 기본 검색 엔진으로 검색합니다. 아래 검색 엔진 버튼과 `!g`, `!d`, `!p` 단축어를 계속 사용할 수 있습니다. 방향키로 결과를 선택하고 Enter로 실행하며 Escape로 닫습니다.

**검색 자동완성**은 별도 체크 없이 현재 검색 엔진에 맞춰 기본 동작합니다. 기본 검색 엔진이 Google·DuckDuckGo·Yandex이면 해당 서비스에 요청하고, `!g`·`!d`·`!y` 단축키로 검색 엔진을 바꾸면 자동완성도 함께 바뀝니다. 지원하지 않는 Perplexity 등에는 자동완성을 요청하지 않습니다. 이전의 사용 여부·별도 제공자 선택은 사용하지 않습니다. URL·도메인·IP·이메일처럼 보이는 입력은 자동완성에 보내지 않고 로컬 북마크 검색에 사용합니다. 북마크 목록·사용자 세션 쿠키·로그인 정보는 전달하지 않습니다. 검색어는 접근 로그 URL에 넣지 않으며 짧은 메모리 캐시만 사용합니다.

제안 서비스의 네트워크·응답 정책에 따라 자동완성이 일시적으로 불가능할 수 있습니다. 응답 실패나 제한·빈 결과는 안내 오류 없이 건너뛰고 북마크 검색·웹 검색은 유지합니다. 입력·검색 엔진 변경 시 이전 요청과 오래된 결과를 취소합니다. 한글은 조합 중 마지막 음절까지 화면의 전체 입력값으로 자동완성을 요청하고 조합 중 Enter는 검색을 실행하지 않습니다. 제안은 해당 제공자의 검색으로 연결되며, 웹 검색 엔진 단축키에 맞춰 자동완성 제공자도 전환됩니다. Yandex 웹 검색은 `!y`를 지원합니다. Yandex는 한국어 등 일부 검색어에 제안이 없을 수 있으며 이때 자동완성 영역을 표시하지 않습니다. 제공자마다 캐시를 구분하고 요청 한도는 사용자별로 함께 적용합니다.

## 백업·복원과 북마크 관리

로그인 기기는 **계정 · 보안 → 로그인 기기 관리**에서 확인합니다. 현재 기기를 구분해 표시하며 특정 기기 또는 다른 모든 기기를 로그아웃할 수 있습니다. 설정 기능 검색에서 `기기관리`, `세션`, `원격 로그아웃`으로도 찾을 수 있습니다. [로그인 기기 관리 안내](authentication.md#로그인-기기-관리)

설정의 **백업 · 가져오기**에서 내 탭·카테고리·북마크의 이름·URL·아이콘·색상·순서와 업로드한 GIF를 JSON으로 내보내고 복원할 수 있습니다. 관리자는 공통 검색·시계·날씨 설정도 포함할 수 있습니다. 계정·비밀번호·2FA·SSO·API 연결/토큰·외부 모니터링 구성·공개 링크 원본/권한은 이 개인 구성 백업에 포함되지 않습니다. 서버 전체 백업은 PostgreSQL 덤프·`.env`·Garage 스토리지를 함께 보관하세요.

- 암호화 내보내기는 AES-256-GCM과 scrypt(N=131072, r=8, p=1)를 사용합니다. 암호화 비밀번호는 12자 이상이며 서버에 저장하지 않습니다. 비밀번호를 잃으면 파일을 복호화할 수 없습니다.
- 가져오기는 미리 보기 후 병합 또는 덮어쓰기로 적용합니다. 병합은 중복 URL을 제외하고, 덮어쓰기는 백업의 중복 배치와 순서도 보존합니다. 공유 링크는 가져오는 시점에 접근 권한이 있어야 합니다. 미리 보기 후 편집한 경우 다시 미리 봐야 합니다.
- Chrome·Firefox의 북마크 HTML도 미리 보고 원하는 항목만 선택해 가져올 수 있습니다. 폴더 경로를 카테고리 이름으로 보존하며 HTTP/HTTPS 링크만 허용합니다. HTML로 다시 내보낼 수도 있습니다.
- 삭제한 탭·카테고리·북마크와 순서 변경은 **휴지통**에서 30일간 최대 100건 복원할 수 있습니다. 덮어쓰기 직후에는 복원 되돌리기도 가능합니다. 이후 편집과 충돌하면 되돌리기를 거절하여 최신 편집을 보호합니다.

## 공개 링크 권한·서비스 상태·프록시 변경 감지

**그룹 관리**에서 사용자를 배정하고 **공개 링크 관리**에서 모든 사용자 또는 지정한 사용자·그룹에만 링크를 허용할 수 있습니다. 권한을 회수하면 이미 메인에 추가한 공유 링크도 조회·검색·백업에서 숨겨집니다. 관리자는 모든 공개 링크를 확인할 수 있습니다.

**서비스 상태**에서 관리자가 등록한 북마크 URL과 상태 확인 URL을 연결하세요. 온라인(401/403 및 로그인 경로 응답 포함)은 초록, 연결 실패·HTTP 오류는 빨강, 확인 대기는 회색입니다. 메인의 도트는 상태 확인을 활성화한 북마크의 오른쪽 끝에만 표시됩니다. 내부 주소는 별도 허용이 필요하며 루프백·링크 로컬·메타데이터 주소는 차단합니다. 로그인 쿠키를 전달하거나 리다이렉트를 따라가지 않습니다. HTTP 200 로그인 화면은 정상으로 분류될 수 있으므로 서비스 자체의 상태 확인 주소를 지정하는 편이 정확합니다. 401/403 응답은 온라인으로 표시하고 반복 요청을 줄이기 위해 자동 재확인을 하루 동안 유예합니다.

**프록시 변경 감지**는 등록한 NPM·NPG·Zoraxy·사용자 정의 API 연결을 주기적으로 조회하여 신규·삭제·이름 변경을 보여줍니다. 선택하여 승인한 변경만 공개 링크에 반영하며 API 연결 오류를 전체 삭제로 처리하지 않습니다. URL 변경은 기존 URL 삭제와 새 URL 추가로 표시됩니다. 기본은 비활성이고 최소 조회 간격은 5분입니다.

## 빠른 추가·개인 설정·다중 편집·즐겨찾기

- 하단바에서 **화면 순서 편집**을 켜면 메인 오른쪽 위에 **+**가 표시됩니다. 편집 모드에서 이 버튼 또는 `N` 키로 **북마크 빠른 추가**를 엽니다. URL을 붙여넣으면 공개 HTML의 제목과 주소·제목에 맞는 로컬 브랜드 아이콘을 채웁니다. 이름과 아이콘은 직접 바꿀 수 있으며 탭을 선택하면 해당 카테고리만 표시됩니다. 내부 주소나 제목을 조회할 수 없는 페이지도 주소 기반 이름으로 저장할 수 있습니다. 미리 보기는 사용자 쿠키를 보내지 않고 공개 주소만 조회하며, 리다이렉트마다 주소를 검증합니다.
- **개인 설정 · 앱 설치**에서 검색 엔진·시계 형식·시간대·날씨 위치·온도 단위·슬라이드 효과를 계정별로 지정합니다. 비운 항목은 관리자 기본값을 따릅니다. 슬라이드는 `기기 설정 따르기 / 항상 켜기 / 끄기`를 지원하며 **항상 켜기**는 해당 계정에서 기기의 동작 줄이기 설정과 관계없이 포털 슬라이드를 표시합니다.
- **내 북마크 → 여러 북마크 편집 · 중복 URL 정리**에서 최대 500개를 골라 카테고리 이동·아이콘/색상 변경·휴지통 이동을 할 수 있습니다. 중복 URL 찾기는 즐겨찾기 항목을 우선 남기고 나머지를 미리 선택합니다. 실제 적용 전 선택을 변경할 수 있고 일괄 작업도 실행 취소할 수 있습니다. 공유 링크의 원본과 다른 사용자의 배치에는 영향을 주지 않습니다.
- 메인 즐겨찾기 영역의 **펜 아이콘** 또는 설정 목록의 별 버튼으로 링크를 고정합니다. 즐겨찾기는 가로 한 줄로 표시하고 화살표·가로 스크롤로 탐색하며, 모바일에서는 좌우로 밀어 볼 수 있습니다. PC 패널은 원래 1200×450의 8:3 비율을 유지하면서 화면 너비의 84% 이내, 최대 1536×576으로 표시합니다. 높이가 낮은 화면에서는 더 줄여 상하 여백도 확보합니다. GIF 중앙의 카테고리 제목도 패널 확대 비율에 맞춰 글자·제목 박스·테두리가 함께 조정됩니다. 하단바와 화면 편집 도구도 같은 너비로 정렬되며, 모바일은 기존 세로 배치를 사용합니다. 즐겨찾기·최근 사용 선택 버튼은 테두리와 활성 배경으로 링크 목록과 구분합니다. 접기 버튼을 누르면 선택 버튼 오른쪽에 링크를 한 줄로 표시합니다. 좌우 화살표로 이동하고 얇은 위치 표시 막대로 현재 구간을 확인할 수 있습니다. 접기 상태는 이 브라우저에서 계정별로 기억합니다. 메인·통합 검색에서 연 링크는 **최근 사용**에 최대 12개 표시되며 기록 지우기로 초기화합니다. 기록은 계정별로 저장하며 공개 권한을 잃은 링크는 목록에서 숨깁니다. 즐겨찾기와 개인 설정은 JSON·암호화 백업에 포함되며 최근 사용 기록은 내보내지 않습니다.

## 크롬·Edge 앱 설치

code-server의 `/proxy/<포트>/`·`/absproxy/<포트>/` 경로에서는 포털의 PWA manifest·서비스 워커·설치 버튼을 등록하지 않습니다. 포털 전용 HTTPS 주소 또는 localhost 직접 접속에서 설치하세요. PWA 식별자는 도메인 루트와 구분되는 `/catppuccindock`입니다. 이전 버전의 프록시 서비스 워커는 포털 자신의 정확한 경로만 등록 해제하며 code-server의 워커·사이트 데이터는 건드리지 않습니다. 이전 PWA 식별자 충돌로 Chrome에 설치한 code-server 앱의 실행 주소가 포털로 바뀌었다면, Chrome에서 해당 설치 앱을 제거한 뒤 code-server 원래 주소를 브라우저 탭으로 열어 다시 설치해야 합니다. 제거 시 사이트 데이터 삭제는 선택하지 마세요.

포털을 HTTPS 주소로 연 뒤 주소창의 설치 아이콘 또는 **개인 설정 · 앱 설치**의 설치 버튼을 사용하세요. 크롬에서는 **메뉴 → 전송, 저장 및 공유 → 페이지를 앱으로 설치**도 사용할 수 있습니다. 설치 버튼은 브라우저가 설치 요청을 허용할 때 표시됩니다. 개발용 localhost 접속도 지원하지만 일반 서버 IP의 HTTP 접속에서는 PWA 설치 조건을 충족하지 못합니다. [Chrome 설치 안내](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DDesktop&hl=ko), [PWA 설치 조건](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

앱 이름·192/512 아이콘·독립 창 실행 매니페스트와 서비스 워커를 제공합니다. 서비스 워커에는 공용 연결 오류 안내 페이지만 저장합니다. 로그인된 HTML·API·북마크·SSO 응답은 캐시하지 않으며 오프라인에서는 서버에 연결할 수 없다는 안내와 재연결 버튼을 표시합니다. `/proxy/<port>/` 같은 하위 경로에서도 매니페스트·아이콘·서비스 워커의 경로를 해당 포털 범위에 맞춥니다.

## 즐겨찾기 표시와 GIF 출처

관리자 **포털 설정 → 즐겨찾기·최근 사용 표시**에서 `아이콘 + 이름` 또는 `아이콘만`을 선택합니다. 아이콘만 표시해도 마우스를 올리면 링크 이름을 볼 수 있습니다. 탭 배경 선택 목록에는 저장된 GIF의 미리보기가 표시됩니다. 메인 GIF에 마우스를 올리거나 키보드로 이동하면 **출처** 링크가 나타납니다. 링크에 마우스나 포커스를 두면 저장된 제목·작성자·라이선스와 표시 방식이 나오며, 클릭하면 원본 정보 페이지를 새 탭으로 열고 버튼을 즉시 숨깁니다. 다시 마우스를 올리거나 키보드로 이동하면 다시 표시됩니다. 터치 기기에서는 출처 링크를 기본 표시합니다. 출처 정보는 **내 북마크 → 탭 수정 → 메뉴 제목 배경** 및 백업에도 남습니다. 제공된 라이선스가 없는 파일은 **이용 조건 확인 필요**로 표시합니다. 이 기능은 사용 허락이나 파일별 조건의 충족을 자동 검증하지 않으며, 별도 저작권 고지·변경 표시 등이 요구되는 경우 원본 조건도 확인해야 합니다.

## 통합 설정 메뉴와 웹 검색 결과

관리자 왼쪽 메뉴는 12개입니다. **공개 링크**에서 추가·관리를, **사용자 · 그룹**에서 사용자·그룹 관리를, **서비스 연동**에서 API 등록·프록시 동기화를 묶었습니다. **계정 · 보안**에는 개인 보안과 **SSO · 로그인** 설정이 함께 있습니다. 내 북마크·개인 설정·포털 설정·GIF·서비스 상태·하단바·백업·휴지통은 직접 열 수 있습니다. 일반 사용자에게는 기존처럼 접근 가능한 6개 메뉴만 표시합니다.

여러 기능이 있는 메뉴는 상단 세부 탭에서 선택하며 방향키·Home·End로도 이동합니다. 메뉴 순서 편집과 기능 검색은 계속 사용할 수 있고 기존 개인별 메뉴 순서도 반영합니다.

**포털 설정 → 웹 검색 결과 열기**에서 `현재 탭에서 열기` 또는 `새 탭에서 열기`를 선택하세요. Enter 검색, Google·DuckDuckGo·Yandex 등 검색 엔진 버튼, 자동완성 선택에 함께 적용합니다. 기본은 현재 탭입니다. 북마크 결과는 기존처럼 새 탭으로 열고, 직접 입력한 URL의 ‘주소로 이동’은 현재 탭에서 엽니다. SSO는 **계정 · 보안 → SSO · 로그인**에서 설정합니다.
